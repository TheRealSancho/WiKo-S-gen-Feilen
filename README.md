# WiKo Sägen und Feilen – https://github.com/TheRealSancho/WiKo-S-gen-Feilen

Live: https://therealsancho.github.io/WiKo-S-gen-Feilen/
iPad: https://therealsancho.github.io/WiKo-S-gen-Feilen/index-ipad.html

Neues themenorientiertes Logo: Feile + Säge gekreuzt (WiKo Feilen)

Reine IHK 100 Punkte Logik (kein internes 75% Ziel mehr):
- 100-92 = Note 1 sehr gut
- 91-81 = Note 2 gut
- 80-67 = Note 3 befriedigend
- 66-50 = Note 4 ausreichend (bestanden ab 50%)
- 49-30 = Note 5 mangelhaft
- 0-29 = Note 6 ungenügend

Features:
- Name Pflicht, 20 Min Timer, Sperre nach Abschluss
- Strenge Auswertung: genau n Kreuze sonst 0 Punkte
- Themenschwerpunkt rot mit Ausarbeitungs-Empfehlung
- Azubi nur eigenes Ergebnis, Ausbilder PIN 9194: Volltabelle, Excel Export, Freigabe, Löschen
- Parallel 14 PCs: OneDrive + Teams Buttons
- 10 Fragen Sägen & Feilen

Installation:
Alle Dateien in Repo https://github.com/TheRealSancho/WiKo-S-gen-Feilen hochladen (Add file > Upload files), dann Settings > Pages > main/root aktivieren.
